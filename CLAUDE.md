# Claude Repository Entry Point

Read `AGENTS.md` first. Then read `docs/INTERFACES.md`, `docs/ARCHITECTURE.md`, the assigned file in `tasks/`, and the nearest nested `AGENTS.md`.

`docs/INTERFACES.md` is the canonical public API. Do not invent or silently modify interfaces, units, shapes, event fields, or ownership boundaries. Run the verification required by `AGENTS.md` and provide a human-reviewable change summary.
